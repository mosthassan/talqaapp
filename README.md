# ⚡ طلقة نت (Talqa Net) — PWA Companion App

تطبيق مرافق رسمي وخفيف للمشتركين لشبكة إنترنت **طلقة نت** (مأرب – اليمن)، المعتمدة على منظومة بث فضائي فائق السرعة عبر ستارلينك (Starlink) وراوترات ميكروتك (MikroTik RouterOS) وكروت هوتسبوت مسبقة الدفع.

---

## 🌟 الميزات الرئيسية المكتملة (Production Features)

1. **بوابة الدخول وخدمات الحساب السريعة:**
   - روابط مباشرة وسريعة لبوابة ميكروتك المحلية `http://t.net` وفحص الرصيد والحالة `http://t.net/status`.
   - تنبيه الاتصال بالواي فاي وحساب زمن الاستجابة الفعلي للبينج (Ping).

2. **باقات الكروت وخريطة مأرب التفاعلية (`/packages`):**
   - استعراض فئات الكروت الرسمية (200، 500، 1000، 4000 VIP ريال يمني).
   - خريطة جغرافية حية بنقاط التوزيع في مأرب عبر Leaflet و OpenStreetMap مع حساب المسافة وساعات العمل وحالة المحل (مفتوح/مغلق).
   - إمكانية طلب الكرت مباشرة عبر واتساب.

3. **مسابقة الانتماء ونظام الولاء السحابي (`/rewards`):**
   - **فكرة المسابقة:** يقوم المشترك بإدخال 10 كروت مستهلكة من كروت طلقة نت، يتم فحصها والتحقق منها وحرقها ذرّياً عبر السيرفر، وتفتح له عجلة الحظ ليربح كرتاً جديداً فائق السرعة فورياً.
   - **بنية Server-Authoritative محكمة:**
     - السحب العشوائي يتم عبر خوارزمية مشفرة `crypto.randomInt` مرجحة بأوزان الفئات على الخادم حصراً.
     - منع تسريب أكواد الجوائز؛ لا يغادر كود الجائزة الخادم إلا للفائز الشرعي بعد اكتمال السحب.
     - ذرّية المعاملات (Atomicity): التحقق من عدم حرق الكروت، حرقها، سحب الجائزة، وتسجيل المعاملة دفعة واحدة. أي فشل أو نفاد في المخزون = تراجع كامل بلا حرق لأي كرت.
     - مفتاح عدم التكرار (Idempotency Key): حماية المشترك من حرق الكروت مرتين عند انقطاع الشبكة أو إعادة الإرسال.
     - مكافحة التلاعب: تحديد معدل الطلبات (Rate Limiting) وتأخير تصاعدي عند المحاولات الفاشلة.
   - **تجربة المستخدم:** شريط دائري (0/10)، لصق دفعة واحدة، مسح QR بالكاميرا، عجلة حظ 60fps على Canvas بأصوات ميكانيكية وهزة خفيفة (vibration) واحتفال Confetti، ومحفظة جوائز محلية لاسترجاع الكروت الرابحة.

4. **لوحة الإدارة المصغّرة المحمية (`/admin`):**
   - محمية بـ Firebase Authentication وصلاحيات المشرفين.
   - **إدارة المحتوى (CMS):** الباقات والأسعار، نقاط التوزيع، الإعلانات، قنوات البث، وعناصر الاستراحة.
   - **صندوق الجوائز (Prize Vault):** إضافة كروت الجوائز فردياً أو عبر لصق CSV، مراقبة المخزون، تنبيهات انخفاض الرصيد، وإخفاء الأكواد افتراضياً مع كشفها عند الطلب.
   - **أوزان وفئات السحب:** تعديل نسب الفئات (1000 ريال 45%، 2000 ريال 30%، باقة 5GB 15%، 4000 VIP 10%) مع فاحص المجموع (100%).
   - **قاعدة كروت الشبكة:** استيراد الكروت المستهلكة من تصدير ميكروتك للتحقق السحابي منها.
   - **سجل المعاملات:** سجل كامل للفائزين والكروت المحروقة مع بحث وتصدير ملف CSV.
   - **التحكم بالمسابقة:** مفتاح تشغيل/إيقاف فوري وسقف يومي لعمليات الاستبدال.

5. **فحص السرعة الفعلي الشامل (`/speed`):**
   - قياس سرعة حقيقي عبر محرك `SpeedTestRunner` بدون أي أرقام وهمية:
   - قياس زمن الاستجابة (Ping) والتذبذب (Jitter)، وسرعة التنزيل والرفع الفعلية بالميجابت/ثانية (Mbps).
   - مزود مزدوج: خوادم Cloudflare Global Edge ومزود داخلي عبر Next.js Route Handlers (`/api/speed/*`).

6. **استراحة الشبكة وبث المباريات HLS (`/lounge` و `/live`):**
   - تصفح أقسام سيرفر الأفلام المحلي Jellyfin والتحميلات السريعة.
   - مشغل Hls.js بدعم الشاشات الكاملة وPicture-in-Picture وScreen Wake Lock لمنع انطفاء الشاشة.

## 🛠️ الحزمة البرمجية (Tech Stack)

- **Framework:** Next.js 15 App Router (React 19 + TypeScript الصارم).
- **Styling:** Tailwind CSS 4 + خطوط محلية Readex Pro و IBM Plex Sans Arabic.
- **Motion & Audio:** `motion` + Web Audio API Synthesizer (أصوات تفاعلية بدون ملفات صوت خارجية).
- **Database & Auth:** Google Firebase (Cloud Firestore + Firebase Authentication + Firebase Admin).
- **Offline / PWA:** Service Worker مخصص `sw.js` بكاش متعدد المستويات وصفحة سقوط `offline.html` وبيان Web App Manifest.
- **Testing:** Vitest (21 اختبار وحدة ناجح بنسبة 100%).

## 🚀 التشغيل والتطوير المحلي (Local Development)

```bash

npm install

# تشغيل خادم التطوير (على المنفذ 3000)

# تشغيل اختبارات الوحدة
npm test

# فحص الجودة والتنسيق (ESLint)
npm run lint

# بناء نسخة الإنتاج المستقلة
npm run build
```

## 🔐 قواعد أمان Firestore (Security Rules)

تتواجد القواعد في `firestore.rules`:
- مجموعات المحتوى العام (`packages`, `distributors`, `announcements`, `channels`, `lounge_items`, `app_settings`): قراءة عامة للجميع، وكتابة محصورة بالمشرفين المسجلين.
- مجموعات المسابقة وصندوق الجوائز (`reward_vault`, `consumed_vouchers`, `reward_claims`, `network_cards_ledger`, `loyalty_idempotency`): **ممنوع قراءتها أو كتابتها من متصفحات العملاء إطلاقاً**؛ كافة العمليات تتم حصراً عبر مسارات الخادم `/api/loyalty/*` لضمان أمان كامل بنسبة 100%.

## ☁️ النشر على Vercel (Deployment)

1. اربط المستودع في منصة Vercel.
2. عيّن متغيرات البيئة من ملف `.env.example` (بيانات مشروع Firebase ومفتاح `ADMIN_EMAILS`).
3. انشر التطبيق على النطاق المعتمد `https://talqanet.vercel.app`.
4. اتبع خطوات قائمة التحقق في `docs/RELEASE_CHECKLIST.md`.
