# دليل حزمة المشغل المحلي (LAN Kit) — شبكة طلقة نت

> **الهدف:** توفير مشغل بث مباشر خفيف ومكتفٍ ذاتياً (`player.html`) يعمل كخدمة محلية مجانية داخل شبكة طلقة نت دون اشتراط وجود كرت إنترنت نشط، وبدون التعرض لحجب المتصفح للمحتوى المختلط (Mixed Content) عند فتح تطبيق الويب عبر HTTPS.

---

## 1. الملفات المرفقة في هذا المجلد
1. `player.html`: صفحة HTML كاملة متوافقة مع الهوية البصرية لشبكة طلقة نت (داكنة مع لمسات ذهبية)، تدعم تقليب القنوات، ملء الشاشة، ونافذة عائمة (PiP).
2. `hls.light.min.js`: مكتبة تشغيل بث HLS مدمجة محلياً (لا تتطلب أي CDN أو اتصال بالإنترنت الخارجي).

---

## 2. خطوات الرفع على سيرفر الملفات المحلي
سيرفر الملفات المحلي في شبكة طلقة نت مضبوط على العنوان `http://192.168.50.2:8080/files/`.

قم بنسخ الملفين إلى مجلد خدمة الملفات في السيرفر (مثلاً عبر SSH أو WinSCP أو لوحة تحكم السيرفر):
```bash
# مثال عبر SCP:
scp lan-kit/player.html lan-kit/hls.light.min.js user@192.168.50.2:/var/www/files/
```

تأكد من أن الرابط التالي يفتح بنجاح من أي جهاز متصل بشبكة طلقة نت:
```
http://192.168.50.2:8080/files/player.html?ch=bein1
```

---

## 3. كيف يستفيد التطبيق من هذا المشغل؟
- عند فتح تطبيق شبكة طلقة نت عبر HTTPS (`talqanet.vercel.app`)، إذا لم تكن شهادة HTTPS مفعلة على سيرفر البث المحلي، سيعرض التطبيق زراً مميزاً:
  **«تشغيل عبر المشغل المحلي (LAN Player)»**.
- بمجرد الضغط عليه، سينتقل المتصفح إلى المشغل المحلي في رابط HTTP أصلي، مما يمنح المشترك بثاً مستقراً 100% بدون حجب وبدون استهلاك رصيد كرت.

---

## 4. إعدادات القنوات المضمنة
- `ch=bein1`: beIN Sports HD 1 (`http://192.168.50.2:8888/live/bein1/index.m3u8`)
- `ch=bein2`: beIN Sports HD 2 (`http://192.168.50.2:8888/live/bein2/index.m3u8`)
- `ch=ssc1`: SSC Sports 1 HD (`http://192.168.50.2:8888/live/ssc1/index.m3u8`)
