# نظام التصميم المعتمد (Talqa Net Design System) — الهوية الملكية والشبكية

> **المفهوم الجوهري:** هوية خاصة ومميزة صُممت خصيصاً لشبكة **طلقة نت**:
> الجمع بين **اللون الذهبي الملكي** (`#C59424`) الذي يرمز للريادة والقوة والسرعة الفائقة لـ «الطلقة»، مع **الأزرق الشبكي السيان** (`#0284C7`) المعبر عن ترددات شبكات الإنترنت الفضائي (Starlink) والألياف الضوئية، فوق خلفيات دافئة مريحة للعين وخالية من السواد القاتم.

---

## 1) رموز التصميم الأساسية (Design Tokens)

معرفة بالكامل في `app/globals.css`:

### 1.1 لوحة الألوان المعتمدة (Talqa Net Palette)
| الرمز | القيمة | الاستخدام والدور الوظيفي |
|---|---|---|
| `--gold` | `#C59424` | اللون الذهبي الملكي: الزر الرئيسي لبوابة `t.net`، كبسولة التنقل النشطة، وشعار الشبكة |
| `--gold-light` | `#E5B338` | التدرج اللوني الذهبي العلوي وبريق الأزرار |
| `--gold-dark` | `#9A6F12` | حدود الأزرار الذهبية والظلال المتناسقة |
| `--gold-soft` | `#FDF7E7` | تظليل بطاقة مسابقة الولاء والكبسولات الذهبية الناعمة |
| `--gold-border`| `#EEDAA2` | حدود البطاقات الذهبية |
| `--network` | `#0284C7` | الأزرق الشبكي السيان: قوس حلقة الإشارة (Signal Ring)، مؤشرات الاتصال بالإنترنت، وحالات LAN |
| `--network-soft`| `#E0F2FE` | تظليل بطاقة بث المباريات وقنوات HLS |
| `--ink` | `#1C1917` | النصوص الأساسية والعناوين (حبر دافئ مريح للعين بتباين 100% WCAG AAA) |
| `--ink-2` | `#57534E` | النصوص الثانوية والتفاصيل الهادئة |
| `--line` | `#E7E5E4` | الحدود الشعرية والفواصل الخفيفة |
| `--bg` | `#F8F8F7` | خلفية التطبيق العامة (رمادي دافئ مهدئ للبصر) |
| `--surface` | `#FFFFFF` | خلفية البطاقات والقوائم والورقات السفلية |

### 1.2 الطباعة والخطوط (Self-Hosted Typography)
تُستضاف محلياً في `public/fonts/` للأداء الفوري دون اتصال:
- **خط العناوين والأرقام والأسعار (`--font-heading`):** `Readex Pro` (أوزان 500، 600، 700).
- **خط نصوص المحتوى والقوائم (`--font-body`):** `IBM Plex Sans Arabic` (أوزان 400، 500، 600).

### 1.3 شعار طلقة نت الجديد (`BrandLogo.tsx`)
شعار أصلي خاص يجمع بين:
1. انطلاق **الطلقة الخارقة** عبر حرف «ط» الهندسي المتكامل مع برج وهوائي البث الفضائي بالذهب الخالص.
2. **أقواس ترددات شبكة الإنترنت** المتداخلة باللون الأزرق الشبكي.
3. متوفر بأشكال: الذهبي الملكي (`variant="gold"`)، الأبيض المفرغ (`variant="white"`).

## 2) مكتبة المكونات المعتمدة (Core UI Components)

يمكن معاينة كافة المكونات حياً في: `/design`.

| المكون | التحديثات البصرية |
|---|---|
| `BrandLogo` | شعار طلقة نت الأصلي بالذهب والأزرق الشبكي المتجهي |
| `Button` | إضافة النمط الذهبي الرئيسي `variant="gold"` والشبكي `variant="network"` |
| `SignalRing` | قوس إشارة ترددات الإنترنت بالأزرق السيان وزر الفحص بالذهب الملكي |
| `Badge` | شارات ذهبية ملكية وشارات شبكية زرقاء |
| `Card` | بطاقات `gold-soft` لمسابقة الولاء و `network-soft` لبث المباريات |
| `Chip` | اختيار الفئات بالذهب الملكي المتدرج |
| `BottomNav` | شريط تنقل سفلي طائف بكبسولة ذهبية متحركة بنعومة عبر Motion |
| `DistributorsMap` | خريطة Leaflet و OpenStreetMap تفاعلية بعلامات مخصصة ذهبية وشبكية |
| `HlsVideoPlayer` | مشغل HLS مع ضوابط متكاملة (PiP، ملء الشاشة، Wake Lock، مستويات الجودة) |
| `SpeedTestView` | عداد سرعة حي 60fps ورسم بياني مصغر Sparkline ومشاركة النتيجة |
